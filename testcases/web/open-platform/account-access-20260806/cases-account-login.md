## 前置条件

- 当前 run 已产生并经用户确认审核通过的合成企业，登录账号与密码只保存在本地 Secret。
- 登录只允许一次受控提交；出现安全挑战时由用户最小接管。

## 操作步骤

| 序号 | 操作 | 输入 | 预期 |
| --- | --- | --- | --- |
| 1 | 使用受控手机号和密码登录 | 本地 Secret 引用 | 登录成功，页面进入已认证状态 |
| 2 | 只读核对当前账号和企业身份 | 当前 run 的脱敏企业句柄 | 页面显示与该审核通过企业一致的账号/企业归属 |

## 预期结果

- 审核通过后取得的受控账号可以登录，且登录后企业身份与当前 run 产生的合成企业一致。
- 手机号、密码、Cookie、Token 和会话不进入日志、截图、Trace、history 或报告。
