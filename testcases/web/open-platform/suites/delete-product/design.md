## 测试范围

- 覆盖开放平台「删除产品」功能直接链路：产品开发首页操作列删除入口、点击【删除】显示【删除确认】弹窗、确认/取消两条路径、开发中产品删除成功后从列表移除且按产品 model/名称/型号搜索不可见、删除状态约束（开发中、测试未通过可删除；送审中、测试中、测试通过未上线、上线审核中、已上线不可删除；产品上线后不支持删除）、操作列按钮随开发状态显示（开发中/测试未通过显示继续开发，其余显示开发详情）、删除无用产品后可继续创建（未上线企业 40 个上限语境下的删除后重建语义）。
- 前置依赖：登录态初始化复用 `web/open-platform/login-register` 套件经验（滑块安全挑战状态机，EXP-6904ECA9CD6F）；临时测试产品创建复用 `web/open-platform/create-product` 套件已确认规则（三步向导与字段规则），产品创建在本套件内仅作为用例级 ephemeral 数据准备，不重新覆盖创建功能设计。
- 不覆盖产品批量删除；不覆盖产品开发首页筛选、排序、搜索、下载、分页等独立列表功能；不覆盖创建产品向导设计（已由 create-product 套件覆盖）；不通过送审→测试→驳回链路人为构造「测试未通过/送审中/测试中/已上线」状态（该类状态以环境既有数据观察，不足时用例 deferred）；不覆盖 Open API 层删除接口（/api/aiot-open-plat/product/del，属 API 测试类型）；不覆盖 40 个上限的全量边界构造（仅验证删除后可继续创建）。
- 首轮请求交付终点为 testcase_only：用例确认即完成，不生成脚本、不执行业务写入；删除与临时产品创建类用例标注执行门禁（写入授权在执行请求单独确认）。

## 需求歧义与未定义预期

| 项 | 需求原文 | 影响 | 处置 |
| --- | --- | --- | --- |
| 删除确认弹窗按钮文案与结构未定义 | 「点击【删除】，显示【删除确认】弹窗」 | 无法断言具体按钮文字与弹窗内容 | 用例采用中性表述（确认路径/取消路径），执行前以真实页面确认弹窗契约 |
| 「不可删除」的页面呈现方式未定义 | 「送审中、测试中、测试通过未上线、上线审核中、已上线不可删除」 | 断言口径不唯一（入口缺失/置灰/点击拦截） | OPEN-DEL-004 以「无可用删除路径（以真实页面呈现为准）」观察并记录实际呈现方式 |
| 测试未通过状态无法由创建链路构造 | 「开发中、测试未通过状态下的产品可以删除」 | 该状态需送审→测试→驳回链路，确定性测试数据不可得 | OPEN-DEL-005 依赖环境既有数据观察；环境不足时该用例 deferred，不人为构造送审链路 |
| 「产品上线后，不支持删除」与已上线条目语义重叠 | 「已上线不可删除」「该产品上线后，不支持删除」 | 无实质冲突 | 合并为已上线状态约束理解，不单列用例 |
| 测试未通过状态操作列文案两处口径冲突 | 统一说明：「产品开发首页操作列显示"重新开发"」；产品开发首页P0：「开发中、测试未通过，显示继续开发」 | 无法唯一断言测试未通过产品的开发入口文案 | 已裁决：按「产品开发首页P0」段【继续开发】定稿（2026-08-19 用户决定，rev-dp-r1-combined F-01），OPEN-DEL-005/RULE-DP-005 移除中性表述 |
| 「企业上线过 1 个产品则无数量限制」子句未建模 | 「只要企业上线过 1 个产品则无数量限制」 | 上限规则第二子句超出删除功能直接链路，且验证依赖企业上线历史 | 不建模；OPEN-DEL-006 仅验证删除后可再次创建的可行性（rev-dp-r1-combined F-03） |
| 删除后搜索不可见与取消后保留为推导后验 | 需求删除段与搜索段均无删除后行为、取消后行为表述 | OPEN-DEL-002/003 的断言是删除语义的合理推导而非需求原文 | 按推导口径断言并在执行时以真实页面验证（rev-dp-r1-combined F-04） |

## 缺口与风险

| 风险 | 等级 | 处置 |
| --- | --- | --- |
| 删除与临时产品创建类用例（OPEN-DEL-001/002/003/006）执行时产生真实业务写入与删除 | 高 | 本轮 testcase_only 仅确认设计；执行需在执行请求单独确认不可变执行清单；临时产品按 ephemeral_cleanup 收口（OPEN-DEL-003 的删除即为临时产品A 的清理，OPEN-DEL-006 自含创建→删除→重建→清理闭环；执行中断时按 cleanup 契约补删残留临时产品） |
| 不可删除状态与测试未通过状态依赖环境既有产品数据 | 中 | 执行前以环境实际数据确认基准；不足时 OPEN-DEL-004/005 标记 deferred，不接管环境既有产品，不触发其删除 |
| 删除确认弹窗契约（文案/按钮）未在需求文档定义 | 中 | 中性表述 + 执行前以真实页面确认（见需求歧义表） |
| 40 上限全量边界需要大量写入构造 | 中 | 本套件仅验证「删除后可继续创建」语义；上限边界不在本轮构造 |
| 登录可能触发滑块安全挑战 | 中 | 沿用 login-register 套件状态机：人工仅完成挑战，脚本自动恢复 |
