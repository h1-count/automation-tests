# 第三方登录与体验质量用例包

## 测试用例：用户从第三方入口进入受控 OAuth 授权页

| 项目 | 内容 |
| --- | --- |
| 用例编号 | LAZYCAT-AUTH-010 |
| 需求追溯编号 | REQ-AUTH-011 |
| 规则覆盖编号 | RULE-AUTH-009 |
| 模块 | 第三方登录 |
| 优先级 | P1 |
| 测试类型 | App |
| 状态 | 草案 |
| 目标环境 | test |
| 自动化状态 | 受控执行 |
| 风险等级 | 高 |
| 是否需要人工确认 | 是 |

前置条件：OAuth 测试提供方或明确测试桩可用，不使用个人第三方身份。

| 序号 | 操作 | 输入 | 预期 |
| --- | --- | --- | --- |
| 1 | 点击微信、Apple 等已展示的第三方图标 | 无 | 跳转到相应的受控授权页。 |
| 2 | 完成或模拟最小授权返回 | 测试身份 | App 接收授权返回且不请求非必要信息。 |

预期结果：入口与授权跳转符合 OAuth 受控边界。

覆盖关联：接口、集成与契约；OAuth 入口。  
assumptions：具体支持图标以实际 App 为准。  
missingInfo：授权取消/失败后的需求预期。

## 测试用例：第三方身份已绑定或未绑定手机号时进入正确分支

| 项目 | 内容 |
| --- | --- |
| 用例编号 | LAZYCAT-AUTH-011 |
| 需求追溯编号 | REQ-AUTH-011 |
| 规则覆盖编号 | RULE-AUTH-009 |
| 模块 | 第三方登录 |
| 优先级 | P0 |
| 测试类型 | App |
| 状态 | 草案 |
| 目标环境 | test |
| 自动化状态 | 受控执行 |
| 风险等级 | 高 |
| 是否需要人工确认 | 是 |

前置条件：准备分别已绑定和未绑定手机号的 OAuth 测试身份。

| 序号 | 操作 | 输入 | 预期 |
| --- | --- | --- | --- |
| 1 | 使用已绑定身份完成授权 | 已绑定测试身份 | 直接登录并进入首页。 |
| 2 | 使用未绑定身份完成授权 | 未绑定测试身份 | 引导手机号与验证码验证；完成绑定后登录。 |

预期结果：绑定状态决定的分支和后续结果正确。

覆盖关联：业务规则、集成一致性；绑定状态决策表。  
assumptions：测试身份可重复使用或可清理。  
missingInfo：绑定失败/取消的需求预期。

## 测试用例：认证页面在交互、性能、弱网和代表设备条件下保持可用

| 项目 | 内容 |
| --- | --- |
| 用例编号 | LAZYCAT-AUTH-012 |
| 需求追溯编号 | REQ-AUTH-012、REQ-AUTH-013 |
| 规则覆盖编号 | RULE-AUTH-010 |
| 模块 | 认证体验质量 |
| 优先级 | P1 |
| 测试类型 | App |
| 状态 | 草案 |
| 目标环境 | test |
| 自动化状态 | 受控执行 |
| 风险等级 | 中 |
| 是否需要人工确认 | 是 |

前置条件：提供 Android 8+、iOS 12+代表设备和网络调控能力；性能测量口径已确认。

| 序号 | 操作 | 输入 | 预期 |
| --- | --- | --- | --- |
| 1 | 聚焦/失焦输入框，点击按钮并触发错误 | 非真实错误输入 | 焦点高亮与按压反馈可见；Toast 约 3 秒消失。 |
| 2 | 测量页面加载和认证接口响应 | 无敏感数据的测试会话 | 页面小于 2 秒、接口小于 500 ms。 |
| 3 | 在弱网下提交一次认证动作并恢复网络 | 隔离测试身份 | 可重试且不重复提交。 |
| 4 | 在两类代表设备观察布局 | Android/iOS | 无布局错乱。 |

预期结果：认证页面的交互、性能、恢复和兼容性符合需求。

覆盖关联：交互、性能、兼容性与恢复路径。  
assumptions：性能和弱网工具可用。  
missingInfo：接口计时边界与弱网等级。
