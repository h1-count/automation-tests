# 用例包：密码重置

## 测试用例：重置身份页校验11位手机号、协议和验证码按钮状态
| 项目 | 内容 |
| --- | --- |
| 用例编号 | LAZY-AUTH-012 |
| 需求追溯编号 | REQ-AUTH-004 |
| 规则覆盖编号 | RULE-AUTH-012 |
| 模块 | password-reset |
| 优先级 | P0 |
| 测试类型 | App |
| 状态 | 草案 |
| 目标环境 | test |
| 自动化状态 | 暂不可执行 |
| 风险等级 | 中 |
| 是否需要人工确认 | 是 |
| 来源 | V1.2“重置密码（身份验证页）” |
| 前置条件 | 已进入重置密码页。 |
| 操作步骤 | 输入非数字/非11位号码；再输入11位号码并勾选协议、请求验证码。 |
| 预期结果 | 非法输入红框并提示错误；合法且勾选后按钮可点击，发送后进入倒计时。 |
| 合理推断（assumptions） | 无 |
| 待补充信息（missingInfo） | 短信测试通道。 |

## 测试用例：符合复杂度且一致的新密码重置成功后返回登录

| --- | --- |

| 需求追溯编号 | REQ-AUTH-004 |
| 规则覆盖编号 | RULE-AUTH-014 |
| 模块 | password-reset |
| 优先级 | P0 |
| 测试类型 | App |
| 状态 | 草案 |
| 目标环境 | test |
| 自动化状态 | 暂不可执行 |
| 风险等级 | 高 |
| 是否需要人工确认 | 是 |
| 来源 | V1.2“设置新密码页” |
