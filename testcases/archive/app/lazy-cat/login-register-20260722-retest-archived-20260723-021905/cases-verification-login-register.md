## 测试用例：新用户自动注册进入首页

| 项目 | 内容 |
| --- | --- |
| 用例编号 | LAZY-NEW-001 |
| 需求追溯编号 | REQ-AUTH-001 |
| 规则覆盖编号 | RULE-AUTH-001 |
| 状态 | 草案 |
| 目标环境 | test |
| 数据策略 | 受控残留 |

## 来源

[需求文档](../../../../sources/requirements/lazy-cat/V1.0%20懒猫慧居app产品需求文档.docx)，V1.2 验证码登录。

## 前置条件

- test 环境、懒猫 App 和可接收验证码的合成新用户手机号已准备；短信操作仅在取得执行授权后进行。

## 操作步骤

| 序号 | 操作 | 输入 | 预期 |
| --- | --- | --- | --- |
| 1 | 打开登录页并填写合成新用户手机号 | `${newUserPhone}` | 验证码登录页显示手机号与验证码输入框。 |
| 2 | 填写验证码但不勾选协议并尝试提交 | 人工安全接管的验证码 | 注册/登录主按钮置灰或提交被拦截，不建立会话。 |
| 3 | 勾选用户协议并获取验证码 | 无 | 发送后显示“60s 后重新获取”倒计时，倒计时期间不可重复获取。 |
| 4 | 在人工安全接管后填写有效验证码并提交 | 人工安全接管的验证码 | 系统自动完成注册、创建名称为“我的家”的默认家庭并直接进入首页。 |

## 预期结果

- 新用户无需额外注册页面即可完成注册，自动创建“我的家”，并直接进入首页。

## 测试用例：验证码输入异常

| 项目 | 内容 |

| 用例编号 | LAZY-NEW-003 |
| 需求追溯编号 | REQ-AUTH-001 |
| 规则覆盖编号 | RULE-AUTH-003 |
| 状态 | 草案 |
| 目标环境 | test |
| 数据策略 | 无写入 |

## 来源

[需求文档](../../../../sources/requirements/lazy-cat/V1.0%20懒猫慧居app产品需求文档.docx)，V1.2 验证码登录。

## 前置条件

- 登录页可访问，且不提交真实手机号或验证码。

## 操作步骤

| 序号 | 操作 | 输入 | 预期 |
| --- | --- | --- | --- |
| 1 | 打开登录页并输入非数字或其他资料明确非法格式的手机号，尝试获取验证码 | `invalidPhone` | 验证码登录 Tab 为默认高亮；手机号、验证码输入框与“获取验证码”控件可见；页面 Toast 显示“请输入正确的手机号”约 3 秒，且不发送短信。 |
| 2 | 对合规测试手机号在 1 分钟内再次请求验证码 | `${existingUserPhone}` | 页面维持倒计时/频控状态且不重复发送。 |
| 3 | 对合规测试手机号输入错误或超过 5 分钟有效期的验证码并提交 | `invalidCode` | 页面 Toast 显示“验证码错误或已过期，请重新获取”约 3 秒，且不建立登录状态。 |

## 预期结果

- 非法格式、1 分钟内重发以及超过 5 分钟的验证码均被拦截，不产生登录状态或重复注册。
