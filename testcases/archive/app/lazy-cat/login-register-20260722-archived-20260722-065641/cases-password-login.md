# 密码登录

来源：[懒猫慧居 App 产品需求文档](../../../../sources/requirements/lazy-cat/V1.0%20懒猫慧居app产品需求文档.docx)，V1.2，“注册登录模块”。

## 测试用例：密码登录页的协议门禁和密码显隐可观察

| 项目 | 内容 |
| --- | --- |
| 用例编号 | LAZYCAT-AUTH-005 |
| 需求追溯编号 | REQ-AUTH-003、REQ-AUTH-006 |
| 优先级 | P0 |
| 状态 | 草案 |
| 目标环境 | test |
| 自动化状态 | 可执行（待 Appium） |

| 操作 | 预期 |
| --- | --- |
| 切换密码登录；切换密码显示/隐藏；未勾选协议尝试登录并打开协议详情 | 密码内容显示状态切换正确；未勾选时登录禁用；用户协议和隐私协议详情均可达。 |

## 测试用例：连续五次密码错误触发图形验证码且辅助入口正确

| --- | --- |

| 目标环境 | test |
