# 验证码登录与注册

来源：[懒猫慧居 App 产品需求文档](../../../../sources/requirements/lazy-cat/V1.0%20懒猫慧居app产品需求文档.docx)，V1.2，“注册登录模块”。所有数据均为隔离占位数据，不记录手机号或验证码真实值。

## 测试用例：验证码登录页在首次打开时展示默认结构并可切换登录方式

| 项目 | 内容 |
| --- | --- |
| 用例编号 | LAZYCAT-AUTH-001 |
| 需求追溯编号 | REQ-AUTH-001 |
| 优先级 | P0 |
| 状态 | 草案 |
| 目标环境 | test |
| 自动化状态 | 暂不可执行 |

前置条件：已启动受测 App 并进入登录页。

| 操作 | 预期 |
| --- | --- |
| 首次查看登录页；点击“密码登录” | 默认“验证码登录”高亮且展示手机号、验证码、协议、第三方入口；切换后展示密码登录内容。 |
