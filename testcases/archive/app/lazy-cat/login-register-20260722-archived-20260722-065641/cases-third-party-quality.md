## 测试用例：认证流程在性能、弱网和代表设备上保持稳定

| 项目 | 内容 |
| --- | --- |
| 用例编号 | LAZYCAT-AUTH-012 |
| 需求追溯编号 | REQ-AUTH-008、REQ-AUTH-009 |
| 优先级 | P1 |
| 状态 | 草案 |
| 目标环境 | test |
| 自动化状态 | 受控执行 |

前置条件：网络调控、Android 8+/iOS 12+代表设备、性能计时口径和脱敏安全审计证据已确认。

| 操作 | 预期 |
| --- | --- |
| 测量页面加载和接口响应；在弱网下重试登录提交；在代表设备上检查布局；核对脱敏安全证据 | 页面加载小于 2 秒、接口响应小于 500 ms；重试不重复提交；布局无错乱；密码无明文传输/存储证据且 OAuth 符合 2.0 最小授权。 |
