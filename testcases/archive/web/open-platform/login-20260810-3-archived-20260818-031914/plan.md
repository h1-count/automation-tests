## 测试范围

### 包含

- 开放平台登录入口落点：“立即使用”、“登录/注册”、“AIoT 控制台”三个入口均进入统一登录页（`/login`）且默认选中“登录”页签。
- 登录页账号密码登录控件结构：账号密码登录切换、手机号输入框、密码输入框、登录用户协议勾选框、登录按钮的可见性与稳定语义；登录/注册页签结构。
- 手机号与密码登录主路径：复用本机已配置的测试管理员账号，完成受控登录并进入已认证的控制台落点；登录提交后可能出现的滑块拼图或首次设备二次验证等安全挑战，由用户在同一可见浏览器会话内最小人工接管，脚本不读取、不记录、不伪造、不绕过。
- 登录后身份可见状态：登录成功后只读核对账号登录态与归属企业身份可见。
- 未满足登录条件（手机号格式无效或凭据缺失）时不建立已认证状态。

### 不包含

- 注册、忘记密码、修改手机号或密码、企业成员管理、系统权限开通、产品开发与设备操作。
- 登录失败的精确文案断言、登录密码复杂度断言（需求未定义，不生成猜测性通过/失败断言）。
- 生产环境、真实用户凭据、绕过滑块或验证码等安全挑战。

## 测试方式

- Web Playwright；先从受控资料生成用例，用例确认后才读取被测源码并生成候选脚本。
- 入口与控件结果使用 DOM/ARIA、文本、页面路由状态断言；登录主路径使用路由落点与已认证语义断言。
- 证据策略（经用户确认）：功能性界面（登录页、三入口落点、登录控件结构、登录后控制台、路由状态等非敏感画面）采集截图/视频作为测试报告证据；仅在密码、OTP、手机号、Cookie、Token、会话原文的输入与传输瞬间禁止截图、Trace、视频、DOM/HTML dump 与请求/响应正文（强制安全边界，不可放宽）。截图/视频不含敏感数据原文：密码框以掩码呈现、手机号脱敏、会话原文不入产物。

### 写入策略明细

- 登录不创建或修改任何业务实体；登录主路径的唯一副作用是建立本地认证会话（`.auth/`，Git 忽略），不计入业务数据预算。
- 登录主路径复用本机已配置的测试管理员账号（`OPEN_PLATFORM_PRODUCT_ADMIN_USERNAME_TEST` / `OPEN_PLATFORM_PRODUCT_ADMIN_PASSWORD_TEST`），凭据原文只存于本地 `.env`，不进入计划、用例、history、脚本字面量、日志或报告。
- 登录提交为受控单次操作（`authenticate_test_account`，幂等 key，最大 1 次）；结果未知时冻结同一 intent，禁止盲目重传或自动重提交。
- 安全挑战只允许用户在同一可见浏览器会话内最小人工接管；Agent 不读取、记录或伪造挑战答案，超时禁止重发或绕过。
- 台账引用：`.local/test-ledger/` 与 `.auth/`，仅保存脱敏本地会话句柄与基线/租约状态。

## 合理推断

- 用户明确复用本机已配置的测试管理员账号作为登录主路径受控凭据；这不等于已授权自动重提交、绕过安全挑战或生产环境访问。
- 需求明确“立即使用”跳转登录；“登录/注册”与“控制台”进入登录页沿用同分支 20260806 已视觉复核的贴图与既定入口语义，不将“登录/注册”断言为直接进入注册页。
- 登录主路径的安全挑战（滑块拼图、首次设备二次验证）按既定项目经验只允许同一可见浏览器会话内的最小人工接管，不解读为登录失败。

## 待补充信息

- 需求未定义登录失败精确文案、登录密码复杂度、登录控件初始禁用/可用态；不对这些未定义内容生成猜测性通过/失败断言。
- 登录页账号密码登录切换、输入框、协议、按钮与登录后身份的稳定 DOM/ARIA 或路由契约在用例确认后的 build 阶段以源码契约为准。
- 运行时是否与当前受控源码的 ARIA/selector 契约一致，在 build/readiness 阶段核对。

## 风险与审核事项

- 高层写入边界：登录主路径包含受控账号单次登录提交与本地认证会话建立；未经执行清单确认不执行；登录不创建业务实体。
- 安全挑战只允许用户在同一可见浏览器会话内最小人工接管；Agent 不读取、记录或伪造挑战答案，超时禁止重发或绕过。
- 证据策略（经用户确认）：功能性界面（登录页、三入口落点、登录控件结构、登录后控制台、路由状态等非敏感画面）采集截图/视频作为测试报告证据；仅在密码、OTP、手机号、Cookie、Token、会话原文的输入与传输瞬间禁止截图、Trace、视频、DOM/HTML dump 与请求/响应正文（强制安全边界，不可放宽）。截图/视频不含敏感数据原文：密码框以掩码呈现、手机号脱敏、会话原文不入产物。
- 用例阶段按 `case-review-risk-v2` 分级：入口/控件/边界用例为 standard；实际凭据、安全挑战或结果未知的登录主路径与登录态用例为 strict。
