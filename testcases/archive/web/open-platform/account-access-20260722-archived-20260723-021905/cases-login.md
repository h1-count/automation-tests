# 用例包：手机号密码登录

## 测试用例：官网立即使用进入账号登录并校验表单

| 项目 | 内容 |
| --- | --- |
| 用例编号 | OPEN-LOGIN-001 |
| 需求追溯编号 | REQ-LOGIN-001 |
| 规则覆盖编号 | RULE-LOGIN-001、RULE-LOGIN-002 |
| 状态 | 草案 |
| 目标环境 | test |
| 数据策略 | 无写入 |

## 来源

[AIoT平台项目.docx](../../../../sources/requirements/open-platform/AIoT平台项目.docx)（官网改造 → 登录），[登录页面.html](../../../../sources/prototypes/open-platform/登录页面.html)。

## 前置条件

- test 登录页可访问，未建立登录会话。

## 操作步骤

| 序号 | 操作 | 输入 | 预期 |
| --- | --- | --- | --- |
| 1 | 从 test 官网首页点击“立即使用” | 无 | 进入认证页面；不直接将官网首页当作登录页。 |
| 2 | 若认证页默认验证码登录，则点击“账号登录”切换；观察账号登录表单 | 无 | 可见手机号、密码和登录提交入口；不对默认登录方式作业务断言。 |
| 3 | 输入空值、格式错误与合规的测试手机号，不提交登录 | `${invalidPhone}`、`${validPhone}` | 空值或格式错误出现可观察校验状态；合规输入可进入后续填写状态。 |
| 4 | 填写非敏感占位密码，不点击提交 | `${passwordPlaceholder}` | 密码字段可输入，且不建立登录会话。 |

## 预期结果

- 官网“立即使用”可进入账号登录；手机号和密码字段按常见表单规则提供可观察校验。

## 测试用例：安全挑战出现后由人工最小接管并自动恢复

| 项目 | 内容 |
| --- | --- |
| 用例编号 | OPEN-LOGIN-002 |
| 需求追溯编号 | REQ-LOGIN-001 |
| 规则覆盖编号 | RULE-LOGIN-003 |
| 状态 | 草案 |
| 目标环境 | test |
| 数据策略 | 无写入 |

## 来源

[AIoT平台项目.docx](../../../../sources/requirements/open-platform/AIoT平台项目.docx)（官网改造 → 登录）。

## 前置条件

- 已获得单独的登录提交与安全挑战执行授权；提供脱敏测试账号引用。

## 操作步骤

| 序号 | 操作 | 输入 | 预期 |
| --- | --- | --- | --- |
| 1 | 自动填写并提交授权的测试账号 | `${testAccountRef}` | 系统进入登录成功态或显示安全挑战。 |
| 2 | 若显示滑块、图形验证码或其他人机验证，则暂停自动化并由人工完成最小挑战 | 无 | 自动化不绕过、伪造或提交安全挑战。 |
| 3 | 人工完成后，自动重新观察页面并继续可确定步骤 | 无 | 自动确认登录成功态或记录新的安全挑战，避免将挑战完成误判为登录成功。 |

## 预期结果

- 安全挑战只由人工完成；挑战后自动化会恢复观察和确定性步骤。
