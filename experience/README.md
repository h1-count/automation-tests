- [通用项目经验](./general.md)：所有项目复用的测试实践。
- [开放平台专属经验](./open-platform.md)：开放平台项目的资料入口和已知页面范围。

这些文档是快速通道的经验库：用例生成前和测试开始前都必须读取。经验库用于补充已验证的页面范围、数据策略和排错路径；它不是需求真相来源，不能覆盖用户指令或 `sources/` 中的当前资料。

经验写入必须基于已验证的页面、脚本或运行事实，且不得记录真实密码、Token、密钥、Cookie 等可复用凭据或其他敏感信息（测试手机号、测试验证码为合成值，不受此限）。
