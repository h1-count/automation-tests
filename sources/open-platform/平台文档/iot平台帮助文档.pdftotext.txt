平台介绍
概述​
Hommor Aura 平台是集成人工智能（AI）、硬件开发、云服务、App 开发一体化工具链的物联网开发
者平台；整合品牌商、制造商、开发者资源，降低开发门槛，缩短硬件设备的研发周期，加速产品智

# ---- PDF page 2 ----
能化落地；通过统一协议和开放生态，实现不同品牌设备的场景化联动，打破设备孤岛生态，构建协
作共赢的 IoT 开发生态体系。​
服务范围​
Hommor Aura 平台面对不同体量的企业客户群体，提供公有云和本地化部署方案，同时支持定制化开
发，根据企业自身业务诉求，提供设备互联互通、数据可视化、应用私有化等服务。助力企业实现品
牌智能化，并享有独立丰富的智能化产品生态。

1. 硬件智能化
提供设备智能化接入的软硬件开发工作，用标准模组与云云接入的双轨模式，为传统设备智能化升级
提供高效路径。标准模组是集成了通信、计算、传感等功能的标准化模块，可直接嵌入各类设备，如
同为设备装上 “智慧大脑”，无需复杂的底层开发，即可实现设备联网、数据采集等基础智能功能；
而云云接入方式则打通设备与云端的数据通道，让设备能够快速对接 IOT 平台，实现远程控制、状态
监测等进阶功能。通过这两种方式，都能在短时间内完成设备智能化改造，极大降低开发成本与时间
周期，助力企业快速抢占智能市场先机。

2. 云服务
依托金云智联强大的云服务能力，为用户提供稳定、高效的物联网平台。用户无需自建服务器，即可
轻松实现设备接入、数据存储与分析。同时，搭配公版金云智居 app，支持多设备统一管理，涵盖远
程操控、场景联动等功能，帮助用户快速搭建智能应用场景，享受便捷智能生活。

3. 私有化部署
将 IOT 平台服务器部署于客户本地，深度融入企业内部系统。可根据客户需求定制平台界面与功能，
打造专属品牌的 IOT 平台，强化企业品牌形象。同时，保障数据安全性与隐私性，便于企业构建独立
生态体系，整合产业链资源，提升市场竞争力。

4. 定制化App​
根据客户需求定制专属品牌 App。提供设备添加、分组管理、定时任务等基础功能，支持个性化场景
创建，如智能安防、家居节能等。通过简洁直观的交互界面，实现设备的智能化控制与管理，为用户
带来便捷、高效的智能体验。

5. AI语音​
提供高度灵活的语音交互定制服务，用户可自定义唤醒词，打造专属语音指令。同时支持修改语音语
调，适配不同使用场景与用户偏好。结合自然语言处理技术，实现精准语音识别与智能对话，让设备
听懂用户需求，为智能设备交互增添人性化与趣味性。

• 平台账号相关问题
1. 如何注册和登录Hommor Aura 开放平台账号？​
请点击链接，进入注册页面，填写对应的信息即可完成注册，如下图：

# ---- PDF page 5 ----
2. 注册企业账号时提示该企业名称已被使用怎么办？
   当注册企业账号时，提醒该企业名称已被使用过，通常是由于该企业已经在平台上完成了注册，每
   个企业只需要在平台上注册一次即可，其他成员可以由企业管理员通过手机号邀请加入该企业组
   内。
3. 如何退出已登录的Hommor Aura 开放平台账号？​
可以点击页面右上角的账号按钮，展开下拉菜单，点击下拉菜单中的“退出”即可。
4. 一个企业可以有多少个授权账号数量？
   没有数量限制。
5. 用户如何加入其他企业组？有没有加入企业数量限制？
   用户请联系该企业的管理员，通过添加您的手机号来加入该企业组。一个账号没有加入企业的数量
   限制。
6. 如何退出企业组?​
   如果是企业组的成员，可以进入【账号中心-所属企业】，点击【退出企业】，点击【确定】即可
   退出该企业。
   如果是企业组的管理员，只能移交管理员权限给同企业内的其他成员后，才能退出该企业组。
7. 金云智居App账号能不能登录Hommor Aura 平台账号？​
   不支持，App账号和 AIoT 平台账号是分别管理的，相互独立的。​
• 产品开发相关问题
1. 产品model代表的是什么？​
Model 是开发者平台为开发者的产品指定的唯一产品标识（用户不可见），是由“企业标识”、“产
品类型”和“产品型号”三部分构成。产品创建后产品 Model 将无法修改。​

# ---- PDF page 6 ----
2. 设备id（DID）代表的是什么？​
设备 ID(Device ID)是开发者平台分配的，用于唯一识别某一个具体设备的唯一标识。使用iKinglink模
组的设备，模组中自带 DID。​
3. 联网模组
联网模组是一个可以集成到目标电子系统的元器件，联网是指连接到网络。联网模组就是将嵌入式系
统连接到网络的电路模组。我们平台支持 Wi-Fi 和蓝牙双模模组、Zigbee模组、PLC模组。​
4. 平台无法创建产品是为什么？
   可能是登录时间太长，页面已失效，建议您重新登录。
5. 产品名称是否可以不包含品牌名称？
   不可以，产品名称必须包含品牌名称。
6. 产品型号怎么填写？
   建议填写内部型号名称或客户产品型号，支持小写字母或数字，6字符之内，便于您在平台上进行
   产品维护以及订单管理。
7. 创建完产品，选择智能化方式时，“免开发接入”、“模组SDK接入”、“开放协议接入”、“云
   云接入”有什么区别？
   免开发接入：适用于采用金云模组、App及配套服务，无需代码开发。具体介绍请看文档：​
   模组SDK接入：适用于采用金云模组和SDK将设备智能化，接入金云IoT。具体介绍请看文档：​
   开放协议接入：适用于采用自研模组，基于平台开放的 MQTT 底层标准协议/SDK接入金云IoT。具
   体介绍请看文档：
   云云接入：适用于成品智能设备通过Open API方式融入金云IoT。具体介绍请看文档：​
8. 创建成功的产品为什么无法删除？
   处于开发中、测试未通过状态下的产品才可删除。
9. 产品的拟物图是否必须与产品实物保持一致？
   产品拟物图需要与产品实物保持一致，需采用产品正面图像，且图像应能清晰呈现产品外观细节，
   以便准确辨认。
10. 为什么产品信息无法再编辑修改？​
   产品状态为“开发中”和“测试未通过”的产品信息都可以修改，其他状态，不能对产品再编辑修
   改。
11. 产品的语音控制能力在哪里配置？​
   默认产品拥有小白的语音控制能力，具体能力需要产品本身支持。
12. 功能定义的时候，可以同时选择多个产品功能模版方案吗？​

# ---- PDF page 7 ----
   不支持同时选择多个产品功能模板，仅支持添加一个产品功能模板，平台提供的产品功能模板下会
   包含多个功能点，这使得即使是不具备专业技能的用户，也能够通过平台提供的各种选项，快速且
   高效地完成个性化智能产品的开发。
13. 什么是必选功能？​
   是该类别下提供的必用功能。免开发方案的功能点固定，不可修改。其他接入方式提供的产品功能
   点您可以直接选择启用，启用后可根据产品实际功能进行编辑。可删除暂时不需要的功能，删除后
   可再次启用。
14. 必选功能是否支持更改标识符、功能类型及数据类型？​
   不支持。
15. 数据传输类型，只上报与只下发指的是什么？​
   只上报：指的是数据只支持从设备端上报，无法从云端下发。 只下发：指的是数据只支持从云端下
   发。
16. 如何增加自定义功能点？​
   如果您需要新增功能点，可以参考链接进行功能点自定义。
17. 如何给模块刷入固件？固件如何选择？​
   ◦ 如果您的产品是免开发，只需要在硬件调试板块配置相关固件信息即可。
   ◦ 如果您是开放协议接入、模组SDK，需要上传您自助开发的固件。​
18. 如何为产品更换模组？​
   如果是开发中的产品，你可以返回到“硬件开发”步骤中，来直接更换合适的模组。
19. 开发完成的设备如何进行试产或量产？​
   如果您的产品已经调试完成，就可以进入产品开发的投产安排，购买试产和量产模组，进行产品上
   线发布和生产。
20. 什么时候可以发布产品上线？​
   产品完成了基础配置、功能定义、交互配置、设备开发、产品测试通过，即可在平台上点击【申请
   上线】，确认产品信息无误后即可申请上线。
21. 产品发布上线的注意事项有哪些？​
   为了保证产品质量和C端用户体验，请确保产品已经过全面测试，通过了平台的产品测试。产品成
   功发布后，产品功能将不能修改，防止影响线上用户使用。 ​

企业成员管理​
为了帮助企业组内拥有不同权限的人员实现多人协作开发管理，Hommor Aura 开放平台提供了企业成
员管理功能。
操作步骤
在控制台页面，切换目标企业，点击【企业】，进入【企业—成员管理】，即可查看和管理当前企业
组内的所有企业成员。平台支持根成员名称、手机号、权限进行筛选操作。




权限说明
当前平台的企业下成员权限分为“管理员”、“成员”两种角色。
管理员默认拥有系统的所有操作权限，可以添加企业成员、修改企业成员信息、删除企业成员。
成员的平台使用权限是管理员分配的，只能查看到企业成员列表。
添加企业成员
1. 点击【添加成员】，根据弹窗的要求填写信息。
2. 点击【确定】，添加成员成功，成员管理列表新增一条

产品开发
智能化方式​
Hommor Aura 平台为开发者提供全面的设备接入、连接与云端集成能力，支持各类设备、网关及服务

开放协议接入​
平台基于 MQTT 的对接协议，为平台统一对外开放提供的对接协议。根据开发灵活度由高到低，分为
MQTT 标准协议和 Hommor Aura Core SDK。开发者可自主选择协议中的一种或两种，用以集成设备
接入。
选择开放协议接入，有以下优势：
• MQTT 标准协议：作为平台开放的标准化通信协议， MQTT 协议完整覆盖设备全生命周期管理（包
   括上下线状态）、属性上报、指令下发等核心交互场景。该协议采用轻量级设计，开发者可基于业
   务需求灵活进行SDK封装，实现跨行业、多品类设备的无缝接入涂鸦开发者平台，尤其适合对内存
   资源及功耗敏感的嵌入式设备场景。
• Hommor Aura Core SDK：Hommor Aura Core SDK封装了 MQTT 协议，在协议基础上添加了业务
   逻辑（如数据编解码、设备管理、安全认证等），让开发者无需深入理解MQTT协议细节，直接实
   现设备与金云开放平台的 MQTT 连接、DP 数据上报、OTA 升级等，适用于设备端嵌入式开发，降
   低第三方开发难度。

这些信息进行验证。如果验证不通过，云平台会拒绝本次连接。这个验证过程就是设备身份认证。

• 动态注册

设备解密数据后连接MQTT服务，注册成功即完成绑定。​
• 手动注册（适用于不支持动态注册的设备）
通过动态注册API接口调用获取设备鉴权凭证，将数据手动烧录至设备，设备使用烧录数据连接服务​

免开发接入​
免代码接入可以帮助您快速完成设备智能化，是设备智能化的高效量产解决方案，以零开发成本实现
快速产品上市。您只需在线选择开发方案，配置设备的信息，平台会依据您配置的信息，将联网模组
寄送给您。将收到的联网模组对接到您的产品上，即可实现您在线配置的功能参数。
当前平台支持的标准化产品品类包括：智能墙壁开关、智能窗帘控制器、场景开关、智能插座（含
USB接口）、紧急呼叫装置及智能温控器等。若您的产品属于上述品类，选择免开发方案将获得以下
优势：
• 极简流程：在线选择方案并配置设备参数后，平台将寄送预置功能的联网模组
• 即插即用：收到模组后简单对接即可实现预设的全部智能功能
• 量产无忧：从原型到批量生产无缝衔接，大幅缩短产品上市周期
该方案特别适合需要快速实现基础智能化功能并投入量产的硬件厂商，帮助您以最小投入获得标准化
的智能设备解决方案。

支持。相比于传统的底层开发，可以快速构建嵌入式固件的方式。SDK开发提供了更高层次的API接
口、示例代码、驱动库和开发工具，使开发者能够专注于业务逻辑，而无需深入硬件细节，选择模组

场景联动​
更新时间：2025-10-26​

智能设备支持跨设备联动与自动化场景设置，让用户享受更便捷、更智能的生活体验。例如，离家时
灯光自动关闭，回家时灯光自动开启。

您可以根据实际需要，决定是否为产品配置场景联动功能，该功能为可选配置。
配置场景联动包含两个关键步骤：设置触发条件和设置执行动作。
• 触发条件：指设备在什么情况下启动联动。通常基于设备的功能点，如属性变化或事件上报。
  例如：电源开关状态变化（如开/关）、温度达到某个设定值等。​
• 执行动作：指满足触发条件后，设备要执行的操作。同样基于设备的功能点，如控制属性或调用方
  法。
  例如：打开电源、关闭电源等。
通过合理配置触发条件与执行动作，即可轻松实现设备间的自动化场景联动。

操作指南
本平台提供两种自动化配置方式，以满足不同场景下的需求：
• 标准自动化
  由平台根据产品的【标准功能点】预先生成，覆盖大多数通用场景。此类型自动化规则不可删除，
  且需实现后上线，适合用于快速部署基础联动功能。

# ---- PDF page 80 ----
• 自定义自动化
 允许开发者自由组合触发条件与执行动作，具备高度灵活性，可满足复杂的业务需求。例如，实
 现“特定用户开锁后，触发家中一系列设备联动”这样的个性化场景。

   ◦ 完成联调自测后，开发者可在开放平台点击【发起上线】，为已配置的标准自动化与自定义自

   ◦ 提交后，系统将生成审核记录进入后台流程；

   ◦ 即使当前存在已上线或审核中的场景，也不影响其他处于“开发中”的场景继续提交审批。

本系列文档介绍 Hommor Aura 开放平台提供的 Wi-Fi 和蓝牙双模模组。Wi-Fi 和蓝牙双模模组具有高
性能和稳定性，适用于多种通信模组领域。Wi-Fi与蓝牙双模技术的协同应用，实现了高速数据传输与
低功耗近场通信的优势互补，为物联网设备提供了更加完善的无线连接解决方案。这种双模架构通过

# ---- PDF page 94 ----
智能协议栈管理和射频资源分配，使设备能够同时维持Wi-Fi的高带宽互联网连接和蓝牙的便捷设备直
连功能。
适用范围
Wi-Fi与蓝牙双模模组凭借其优异的连接性能，可广泛应用于以下核心领域：​
• 智能家居设备：为智能插座、照明灯具、安防门锁等设备提供稳定可靠的无线连接方案。
• 物联网设备：服务于各类环境传感器、视频监控设备的数据采集与传输需求。
• 工业设备：满足生产线控制设备、精密仪器仪表的实时通信要求。
• 消费电子设备：为智能手机、平板电脑等移动终端提供高速稳定的无线连接能力。
核心优势
1. 灵活组网：Wi-Fi支持高速数据传输和远程连接，适用于云端交互；蓝牙适合短距离低功耗通信，如
   设备直连。双模互补，适应不同场景需求。
2. 低功耗优化：蓝牙（如BLE）在待机或低频通信时功耗极低，Wi-Fi仅在需要大数据传输时启用，延
   长设备续航。
3. 简化设计：集成双模减少硬件复杂度，节省PCB空间和成本，适合智能家居、穿戴设备等小型化产
   品。
4. 无缝切换：设备可动态选择最优连接方式（如蓝牙配网后切换Wi-Fi），提升用户体验。​
适用于智能家居、医疗设备、工业物联网等需要兼顾速率与低功耗的场景。

授权设备​
为什么要授权设备
将已激活连接的设备授权至IoT服务项目后，可通过业务系统的开发，实现主动管理和控制相应设备。
平台提供多种授权方式：
• 使用集成了App SDK的移动端应用激活连接的设备，无需重复在平台上授权，IoT服务项目默认获
  取此类设备的管理和控制权限
• 使用iKinglink B端批量交付工具激活连接的设备，需通过登录 智居工程系统 账号关联B端项目，以
  获取指定项目下设备的管理和控制权限

注：
• 授权关联的设备必须是由 智居工程系统 激活连接​
• 智居工程系统 是为有大批量交付需求的客户提供的设备配网和激活工具，系统的使用详询商务人员​
