# 开放平台创建产品：测试结论

## 当前结论（2026-09-01 全量通过）

- 2026-09-01 按最新规范重新设计用例：基于前端源码实现核对（`ProductCreate.vue`、`ProductManagement.vue`、`IptProductCategorySelect.vue`、`ValidationRuleBuilder.ts`、路由与权限），用例集 12 条（七类提取全覆盖），审核工作簿经用户确认后执行。
- 全量执行 **12/12 通过**。`npm run test:fast -- testpacks/web/open-platform/create-product/create-product.spec.ts`。
- 测试环境：test（本地 Vite `http://127.0.0.1:3098/` test 模式，API 直连 `gateway-test.ikingcity.com` 测试后端）。
- **登录态复用策略**：登录功能本身由 `login-register` 功能包覆盖，本包登录仅为前置条件。OP-PROD-002 优先复用 `runtime/auth-state.json`（token cookie，仅存本地不入 Git）中的有效会话——会话有效则跳过短信登录（不发送短信、无需人工点选验证码，002 仅约 4 秒）；仅当会话缺失/过期时才短信登录并刷新该文件。003~012 一律经 storageState 复用该文件。会话有效时全量跑约 1.5 分钟、零人工介入。
- 说明：每轮全量执行 OP-PROD-011 会真实创建 1 个产品（写入用例）；如只想回归校验类用例，可 `--grep "OP-PROD-00[1-9]|OP-PROD-012"` 跳过写入。

## 执行中发现并处理的问题

1. **品类数据偶发不完整**：`queryProductCategoryList` 偶发返回缺 children 的数据，选中一级品类后二级区域为空。脚本在 `selectCategory` 中加重试（重选一级品类，最多 3 次）后稳定。
2. **产品列表字典未命中显示原始值（真实产品缺陷候选，已注解记录）**：开发状态/开发方式/通讯方式/设备类型列显示 `developing/direct/wifi/ordinary` 等原始枚举值而非中文「开发中/开放协议接入/WiFi/普通设备」；`colorful-tag`（字典 `S_INTEGRATION_ACCESS_STATUS` 等）未命中时回退显示原始值。语义与「开发中」一致，OP-PROD-012 以「文案差异」注解记录，建议反馈产品/前端确认字典加载或取值问题。
3. **型号格式提示文案不在通用提示关键词表内**：`仅支持小写字母或数字，最多6位` 不含常见关键词，捕获关键词表已补充「仅支持」。

## 实现与需求的已知差异（源码核对 + 执行实证）

1. 产品名称「不允许标点符号和空格」的字符集校验在 `ValidationRuleBuilder.productName()` 中已整段注释，前端不拦截（OP-PROD-008 执行实证：含空格标点名称无格式提示）。
2. 产品描述需求为「最多200字符」，实现为非必填但填写时长度 3~200（2 字符报「描述长度必须在3~200之间」，OP-PROD-008 实证一致）。
3. 实现新增必填「通讯协议」单选（开放协议接入下 11 项：WiFi/蓝牙/NB-IoT/Zigbee/WiFi+蓝牙/4G/RS485/PLC/以太网/Z-wave/LoRa）与云云接入专属必填「协议类型」（平台标准协议/自定义协议）。
4. 创建成功信号：toast「产品创建成功」+ 自动跳转 `/integration/product/{productId}/basic` 基础配置页（非需求描述的返回列表场景）。
5. 创建为单页三段向导（无「下一步」按钮）：提交按钮可用条件=品类+方案已选，点击时才触发字段校验（OP-PROD-006 实证拦截提示「请输入产品名称/请选择通讯协议/请选择设备类型」）。
6. 产品 model 组成实证：`at0635（企业标识）.light（品类英文）.at5948（产品型号）`，与需求「企业标识+二级品类英文+产品型号」一致。
7. 型号唯一性后端拒绝实证：同品类重复型号提交返回错误码 10516，型号字段提示「产品型号重复」，无写入（OP-PROD-010 实证）。

## 风险与限制

- 登录（短信+图形验证码人工协助）与创建产品提交为外部写入，已获用户确认后执行（2026-09-01）。
- 范围外（用例表头部已声明）：双击幂等、企业 40 个产品上限、文件上传（无控件）、验证码细节（属 login-register 包）、产品删除清理。
- 品类一级标签与二级卡片为纯文本节点（无 button/radio role），脚本按可访问文本 + 项目自有类（`.product-type-item`、`.plan-item`、`.cate-selected`）定位；云云接入「协议类型」label 内含 DotTip 提示组件，可访问名称非精确文本，按子串匹配定位。
