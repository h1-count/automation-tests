# 用例集：开放平台控制台首页（console-home）

> 测试类型：Web ｜ 默认环境：test ｜ 默认数据策略：no_write
>
> 上下文来源：`sources/indexes/open-platform.yaml`、`sources/open-platform/需求/AIoT平台项目.docx`（「AIoT控制台/系统入口」章节）、`sources/open-platform/原型包/控制台.html`（Axure 原型）、前端源码 `web-open-platform/src/pages/console/Home.vue`、`src/pages/console/sys-data.ts`、`src/routes/console.ts`、`src/components/layouts/console/ConsoleLayout.vue`、`src/components/layouts/console/ConsoleHeader.vue`、`experience/general.md`、`experience/open-platform.md`；查重比对 `testpacks/web/open-platform/login-register/cases.md`、`testpacks/web/open-platform/create-product/cases.md`。
>
> 上下文结论：①控制台首页（/console/home）无表单、无提交入口，本包全部用例 no_write，不涉及短信与验证码；②需求文档对控制台首页仅定义「系统入口由金云集中管理平台开通后可见、注册账号默认管理员」，原型含「数据概览/快捷入口」元素，当前实现为「用户信息卡 + 按权限过滤的系统入口列表」，无数据概览区——以源码实现为测试依据；③源码静态发现两处空态文案疑似错别字（「您没还有获得系统使用仅限」「您没还有加入任何企业」），为缺陷候选，待受限账号场景实证后在报告注解；④系统入口点击跳转目标取「第一个启用子权限」（switchSystem 映射）；2026-09-03 探索实证（MCP 登录态受限，按工程既有 storageState 探索脚本模式，快照与截图见包内 runtime/exploration/out/）：三入口 href 与源码一致，产品接入落点经路由重定向为 /integration/product/management，产品运营落点 /device/management、产品服务落点 /service/aiot-develop；测试账号名下两家企业——完整权限企业（3 入口）与受限企业「仅产品创建权限」（仅产品接入入口、无空态），企业切换后入口随权限刷新；⑤测试账号为两家企业的企业管理员；⑥控制台外壳权限校验：会话权限不含路由权限时渲染 Unauthorized 页（未加入企业时附「您当前未加入企业，无法查看此页面。」）；项目 element-plus 命名空间为 ep（下拉选项定位按 ARIA option + ep 前缀）。
>
> 范围外声明：未登录直达 /console/home 重定向登录页——已由 login-register 包「未登录直达受保护页重定向」用例覆盖，不重复设计；登录成功后进入控制台的登录链路——已由 login-register 包「账号密码登录成功路径（含首次设备验证）」用例覆盖；企业切换后的会话与菜单刷新行为——归 account-center / enterprise-center 包，本包仅核对切换控件存在与当前值；验证码过期等验证码细节——属 login-register 包；OP-CONS-010 受限账号空态——对象矩阵保留该行并标注「待确认：需无 aiot 权限成员账号或未加入企业账号」，当前两家企业均含产品接入权限（2026-09-03 探索实证）。
>
> 本表供测试范围审核。真实密码、Token、密钥、Cookie 等可复用凭据仅从本地 `.env` 或对应登录态存储读取；测试手机号、测试验证码为合成值，可正常出现在记录、报告与 trace 中。
