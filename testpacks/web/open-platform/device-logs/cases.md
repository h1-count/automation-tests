# 用例集：开放平台设备日志（device-logs）

> 测试类型：Web ｜ 默认环境：test ｜ 默认数据策略：no_write（本包全部 no_write，无写入入口）
>
> 上下文来源：`sources/open-platform/需求/产品接入系统功能需求说明/产品接入系统功能需求说明.md`（「设备日志」相关章节）、前端源码 `web-open-platform/src/pages/device/Logs.vue`（22 行：标题/描述 + DeviceLogSearch，deviceId 取自 URL query）、`components/DeviceLogSearch.vue`（206 行：默认最近 7 天日期范围 + 设备信息条 + 日志分页表；**deviceId 输入框已注释**，入口仅 URL 参数与设备管理页「日志」链接）、`components/DeviceInfoBar.vue`、`api/device-mgt/device-mgt.ts`（queryDeviceById/queryDeviceLogPage）、`routes/device.ts`、`experience/general.md`、`experience/open-platform.md`；查重比对 device-management（「日志」链接入口在彼包操作列）。
>
> 上下文结论：①页面结构：标题「设备日志」+ 描述（设备操作日志可根据设备ID搜索出该设备七日内的操作日志，可筛选 7 天内指定时间段，更长时间需联系商务开通）+ 日期范围筛选（datetimerange，**默认最近 7 天**：今天-6 天 00:00:00 ~ 今天 23:59:59，实证 2026-08-29 00:00:00 起）+ 设备信息条（有 deviceId 时显示）+ 日志表（序号/设备名称/设备Mac/时间/事件名称/事件详情；按 deviceId 查询时隐藏设备名称/设备Mac 两列）；②**deviceId 搜索入口已注释**：UI 无法手动输入设备 ID，仅支持 URL ?deviceId= 注入或设备管理列表「日志」链接；③查询约束：设备信息查询失败不阻断日志分页查询（catch 返回空集，页面无报错）；④2026-09-03 实证：无 deviceId 直达日志 0 行（台账产品无绑定设备）。
>
> 范围外声明：**真实设备日志查询**（台账产品均无绑定设备，无有效 deviceId 与日志数据——待设备绑定后补）；**设备信息条（DeviceInfoBar）展示**（依赖有效 deviceId 返回设备信息）；**7 天以外历史日志**（需商务开通服务，范围外）。
>
> 本表供测试范围审核。真实密码、Token、密钥、Cookie 等可复用凭据仅从本地 `.env` 或对应登录态存储读取；deviceId 合成值仅用于只读查询。
