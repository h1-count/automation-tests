# 用例集：开放平台账号中心（account-center）

> 测试类型：Web ｜ 默认环境：test ｜ 默认数据策略：no_write
>
> 上下文来源：`sources/indexes/open-platform.yaml`、`sources/open-platform/需求/AIoT平台项目.docx`（「账号中心/账号管理/所属企业」章节）、前端源码 `web-open-platform/src/pages/console/account/AccountInfo.vue`、`src/pages/console/account/Company.vue`、`src/pages/console/components/BtnChangePhone.vue`、`BtnChangePassword.vue`、`PasswordResetForm.vue`、`BtnTransferCompany.vue`、`src/components/layouts/console/ConsoleLayout.vue`、`ConsoleHeader.vue`、`experience/general.md`、`experience/open-platform.md`；查重比对 console-home 包（头部入口跳转已覆盖）、login-register 包（登录/重置链路已覆盖）。
>
> 上下文结论：①账号管理页为只读回显（用户ID/姓名/手机号禁用）+「更换手机」「更改密码」两个弹窗入口，改密码成功仅提示不登出，换手机成功强制登出并使 TEST_PHONE 凭据链失效——换手机不设计写入用例（范围外）；②更改密码与更换手机共用 `changePhoneNPassword` API，验证码发送前置人工点选图形验证码（experience/general.md 协作模式）；改密码弹窗手机号字段禁用并预填当前手机号，新密码 8~32 位、两次一致链式校验，验证码 6 位 custom 校验；③OP-ACCT-005 为本包唯一写入用例：经控制台入口幂等重设密码为 `.env` 当前 `TEST_PASSWORD`（与 login-register 024 重置链路同 API 异入口，重复执行幂等、不改变登录前提），需人工协助；④所属企业页：管理员行操作列仅「转移管理权限」（需求「管理员只可移交不可退出」与实现一致），成员行仅「退出企业」；转移弹窗目标下拉仅查询成员角色成员，当前测试企业为单人企业（或无成员），空目标拦截为安全 no_write 场景；⑤账号子页侧边菜单过滤：隐藏控制台根菜单与企业组菜单，仅显示账号中心组（ConsoleLayout 菜单过滤器）；⑥element-plus 命名空间为 ep，弹窗/选项定位按 ARIA 优先；⑦登录态复用 console-home/create-product 包 auth-state（失效时短信登录自愈，人工协助）。
>
> 范围外声明：更换手机号成功路径——会使 TEST_PHONE 凭据链失效、破坏测试体系登录前提（如需覆盖需提供可丢弃的隔离账号）；转移管理权限成功路径——会使测试账号失去企业管理员角色、破坏后续用例执行前提（需第二成员账号且可回转才可覆盖）；退出企业成功路径——破坏性写入且不可自愈（管理员行不可见该入口；成员行场景见 OP-ACCT-008 fixme 待确认）；验证码过期场景——分钟级等待，属 login-register 包范围外口径；账号头像图片内容与 i18n 文案——纯展示，不作断言对象。
>
> 本表供测试范围审核。真实密码、Token、密钥、Cookie 等可复用凭据仅从本地 `.env` 或对应登录态存储读取；测试手机号、测试验证码为合成值，可正常出现在记录、报告与 trace 中。
