> 上下文结论：①功能定义页为两个垂直步骤：「选择产品功能模板」（IptModuleSelect 卡片栅格：自定义 badge 卡片排第一、标准卡片在后；选中态显示选中卡片+重新选择链接）与「编辑产品功能」（未选模板时 el-empty「请选择产品功能模板」，选中后渲染 属性/Property、事件/Event、动作/Action 三个列表，列头 功能点名称/标识符code/功能类型/数据类型/数据传输类型/场景权限/数据定义/操作[详情+删除]）；②顶部提示文案「设备开发和高级配置都与产品功能定义有关。如何定义产品功能？点我查看」（新窗口打开文档）；③选择模板即写入：必选功能点自动加入 + updateProductConfig 保存模板 + toast「功能模板保存成功」，标准模板还会自动加入全部可选功能点并刷新列表；自定义模板（code=custom）隐藏批量添加按钮、保留「自定义属性」；④删除功能点（仅 non-Required 行有删除链接）：queryProductFunctionUsageInfo 预检 → ElMessageBox「删除确认」（确定/取消，默认文案「确定要删除该功能吗？」）→ deleteProductFunction → toast「功能已删除，请及时保存更改。」；⑤saveStage 守卫：未选模板时切换页面弹「您还没有选择功能点，确定要切换页面吗？」（留在页面/切换页面，注意句尾双句号为源码原样）；页脚为 上一步/下一步/取消（无保存按钮）；⑥写入目标为台账最新产品（当前 自动化测试产品1789026290672 / 型号 at0672 / model at0635.light.at0672，2026-09-10 创建；本包台账尚无该产品的模板/删除记录，空态预期大概率成立，生命周期约定同前）；⑦用户指令（2026-09-11，「测试开放平台产品编辑链路」）：**不创建产品**，全部操作对象为 create-product 功能包台账中既有合成产品（取台账最后一条，即 at0672），「创建产品」相关对象一律按范围外声明或改为基于既有产品的编辑场景；⑧对象矩阵核对（2026-09-11）：①⑤按 入口×路径正负×访问方式、②⑥按 表单×字段×取值类、③按 可重复动作×触发方式 逐类列行，新增直达访问、删除取消分支、页脚正向/反向跳转 4 条用例（008~011），其余行见 `scope.json` 对象矩阵。
>
> 范围外声明：自定义模板全流程（选择 code=custom 后逐个自建功能点的创建弹窗链路——覆盖成本高，仅覆盖标准模板与卡片结构）；「添加属性/事件/方法」批量添加弹窗内部校验（留待后续增强）；「点我查看」文档内容正确性（仅断言新窗口链接属性）；场景权限/功能点编辑（页面实证操作列仅 详情+删除，编辑弹窗未实现，需求与实现差异已记录）；未登录直达功能定义页（登录守卫由 create-product 包「未登录访问创建产品页重定向登录」用例覆盖，跨包查重）；登录态获取与图形验证码人工点选（由 login-register 包覆盖，本包复用 runtime/auth-state.json，失效时按该包用例重建）；功能点被引用的删除预检警告分支（构造引用需跨模块写入，OP-PFNC-006 以注解兜底）；守卫弹窗「切换页面」强制跳转分支（跳转终点行为无实证，待确认：终点页面行为）；删除必选功能点（UI 无删除入口，需求约束与实现一致）；功能定义状态流转与「新建版本」功能迭代（需申请测试上线触发/前置需已上线，台账产品生命周期为开发中）；模板卡片与删除按钮快速连点防重（源码无防重复实现证据，待确认：预期终态）。
