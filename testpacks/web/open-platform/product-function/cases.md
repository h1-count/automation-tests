# 用例集：开放平台产品功能定义（product-function）

> 测试类型：Web ｜ 默认环境：test ｜ 默认数据策略：no_write
>
> 上下文来源：`sources/open-platform/需求/产品接入系统功能需求说明/产品接入系统功能需求说明.md`（「功能定义」章节）、前端源码 `web-open-platform/src/pages/integration/product/ProductPhaseFunction.vue`、`components/IptModuleSelect.vue`、`components/function/FuncPropertyList.vue`（事件/动作列表同构）、`src/support/recordGeneratedData.ts`、`experience/general.md`、`experience/open-platform.md`；查重比对 product-basic 包（阶段容器、下一步守卫已覆盖）。
>
> 上下文结论：①功能定义页为两个垂直步骤：「选择产品功能模板」（IptModuleSelect 卡片栅格：自定义 badge 卡片排第一、标准卡片在后；选中态显示选中卡片+重新选择链接）与「编辑产品功能」（未选模板时 el-empty「请选择产品功能模板」，选中后渲染 属性/Property、事件/Event、动作/Action 三个列表，列头 功能点名称/标识符code/功能类型/数据类型/数据传输类型/场景权限/数据定义/操作[详情+删除]）；②顶部提示文案「设备开发和高级配置都与产品功能定义有关。如何定义产品功能？点我查看」（新窗口打开文档）；③选择模板即写入：必选功能点自动加入 + updateProductConfig 保存模板 + toast「功能模板保存成功」，标准模板还会自动加入全部可选功能点并刷新列表；自定义模板（code=custom）隐藏批量添加按钮、保留「自定义属性」；④删除功能点（仅 non-Required 行有删除链接）：queryProductFunctionUsageInfo 预检 → ElMessageBox「删除确认」（确定/取消，默认文案「确定要删除该功能吗？」）→ deleteProductFunction → toast「功能已删除，请及时保存更改。」；⑤saveStage 守卫：未选模板时切换页面弹「您还没有选择功能点，确定要切换页面吗？」（留在页面/切换页面，注意句尾双句号为源码原样）；⑥写入目标为台账最新产品（当前 at8438，生命周期约定同前）。
>
> 范围外声明：自定义模板全流程（选择 code=custom 后逐个自建功能点的创建弹窗链路——覆盖成本高，仅覆盖标准模板与卡片结构）；功能点的批量添加弹窗内部校验（添加属性弹窗，留待后续增强）；「点我查看」文档内容正确性（仅断言新窗口链接属性）；场景权限编辑。
>
> 本表供测试范围审核。真实密码、Token、密钥、Cookie 等可复用凭据仅从本地 `.env` 或对应登录态存储读取；测试产品与功能点均为本测试体系生成的合成数据。
