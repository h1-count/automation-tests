# 用例集：开放平台设备开发（product-develop）

> 测试类型：Web ｜ 默认环境：test ｜ 默认数据策略：no_write
>
> 上下文来源：`sources/open-platform/需求/产品接入系统功能需求说明/产品接入系统功能需求说明.md`（「设备开发」章节）、前端源码 `web-open-platform/src/pages/integration/product/ProductPhaseDevelop.vue`、`components/DevelopMethodProtocol.vue`（本包产品为开放协议接入→direct→协议直连分支）、`components/DevelopFirmareTable.vue`、`components/BtnEditFirmwareVersion.vue`、`src/utils/ValidationRuleBuilder.ts`（version 规则）、`experience/general.md`、`experience/open-platform.md`；查重比对 authcode 包（授权码申请写入在该包覆盖）与 device-ota 包（设备侧 OTA 在批4覆盖）。
>
> 上下文结论：①设备开发页按 developType 分发，台账产品为 开放协议接入（direct）→ DevelopMethodProtocol：三个垂直步骤「开发资源及资料」（两个 DMStepBox：iKinglink MQTT 标准协议格式 / 设备接入规范，各带「下载文档」链接指向 /resource/docs/*.pdf，target=_blank）、「获取平台产品授权凭证，注册设备到云平台」（第一步 获取设备授权码[BtnApplyAuthCode + 剩余授权码数量：N个]；第二步 获取产品授权凭证[Model/Product Key/Product Secret/Vendor Code 四项 text-copy]；第三步 使用注册设备接口，激活设备验证[注册接口地址 text-copy + 提示 alert]）、「固件配置」（note「含 SDK 固件版本列表」+ 新建版本按钮 + 固件表：固件名称/固件key、固件版本、固件状态、测试OTA固件版本、版本说明、上传时间、操作[查看/编辑/固件升级/删除]）；②固件表单规则：固件名称 required text 3-32、固件类型 direct 固定 Sdk、固件版本号 required version 格式（数字+点分段，如 1.0.0）、上传生产固件 required、版本说明 ≤100；测试 OTA 固件版本需大于生产版本；③保存成功 toast「新增固件成功」；④validate/autoSaveStage 恒成功（本页无表单守卫）；⑤写入目标为台账最新产品（当前 at8438）。
>
> 范围外声明：获取授权码按钮提交（BtnApplyAuthCode 写入由 authcode 包同名组件覆盖，查重不重复设计）；固件「编辑/固件升级/删除」操作链路（固件升级依赖已激活的真实设备，属高风险设备动作红线，仅覆盖新建与查看）；DevelopMethodCloud/DevelopMethodModule 分支（台账产品均为 direct，无 cloud/module 数据）；注册设备接口实际调用（需真实设备烧录，范围外）。
>
> 本表供测试范围审核。真实密码、Token、密钥、Cookie 等可复用凭据仅从本地 `.env` 或对应登录态存储读取；测试固件为本测试体系生成的合成 bin 文件。
