# 用例集：开放平台产品测试（product-testing）

> 测试类型：Web ｜ 默认环境：test ｜ 默认数据策略：no_write
>
> 上下文来源：`sources/open-platform/需求/产品接入系统功能需求说明/产品接入系统功能需求说明.md`（「产品测试」章节）、前端源码 `web-open-platform/src/pages/integration/product/ProductPhaseTesting.vue`、`components/BtnEditTestingApplication.vue`（预约申请表单 175 行）、`components/BtnShowTestingApplication.vue`、`components/BtnSendDevice.vue`（寄送样机，未深入）、`src/utils/ValidationRuleBuilder.ts`（realname/mobile/email 规则）、`experience/general.md`、`experience/open-platform.md`；查重比对 product-develop 包（关联固件来自该包写入）。
>
> 上下文结论：①产品测试页 = 「自测与实验室预约」标题 + 两个垂直步骤（下载资料自测[金云智居APP二维码 + 支持 Android 和 iOS 标签]；实验室测试[金云官方测试实验室卡片：联系人=金云实验室、联系方式=0510-68109900、测试服务说明与测试结果说明文案]）+「申请测试」区（提示 提交申请后，预计2个工作日内给予回复）+ 预约列表；②预约列表列头：实验室名称/测试类型/申请人/预约申请时间/申请状态/计划完成时间/测试结果/操作[查看/修改/寄送样机?]；③预约申请表单：Model 与 企业名称 回显、关联固件版本（非 cloud 显示，required，选项来自 product-develop 固件）、预约测试类型（测试上线/设备升级，required）、预约测试开始时间（默认+3天，不可早于今天）与计划上线时间（默认+10天，不可早于开始时间）、联系人（required realname）/联系电话（required mobile）/邮箱（email），联系人/电话/邮箱从会话用户信息预填；提交成功 toast「预约申请提交成功」；④列表操作无删除（预约不可从 UI 撤销）；修改仅在申请状态=0（待回复）时可用；寄送样机需 状态=1 且非设备升级类型；⑤写入目标为台账最新产品（当前 at8438，已有固件）。
>
> 范围外声明：「寄送样机」（依赖实验室回复状态流转 + 真实物流动作，属线下链路）；「修改预约」（避免对实验室队列重复提交，且幂等轮已有核验路径）；申请状态流转（待回复→已回复/测试中）依赖实验室人工处理，超出自动化范围。
>
> 本表供测试范围审核。真实密码、Token、密钥、Cookie 等可复用凭据仅从本地 `.env` 或对应登录态存储读取；预约联系人信息为会话账号合成资料。
