# 可复用测试能力

`src/` 存放测试脚本复用的实现代码，不存放具体测试场景。脚本应优先组合此处能力，避免复制登录、请求、等待、断言和数据清理逻辑。

| 子目录 | 职责 |
| --- | --- |
| `actions/` | 业务级动作，例如登录、创建产品、设备操作、告警验证。 |
| `clients/` | API、MQTT 等协议连接与底层访问，不承载业务流程。 |
| `fixtures/` | 非敏感测试数据引用、数据生成和初始化能力。 |
| `env/` | 环境变量解析、校验和配置映射。 |
| `support/` | 通用断言、轮询、脱敏日志和清理能力。 |
